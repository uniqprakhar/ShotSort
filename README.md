# ShotSort v1.1 — screenshot asks "Save to which folder?"

Free & open-source Android app. Instagram-Saved style sorting for screenshots.

Take a screenshot → notification **"Sort screenshot?"** → pick a folder (or `+ New folder`) → it's moved there and shows in Gallery as that album.

Name one folder **`Calendar`** — anything you sort there becomes the inbox for your screenshot→Google Calendar automation.

## Install (no computer needed after push)
1. Push this repo to GitHub → **Actions** → latest **Build APK** run → download **shotsort-apk** → install the `.apk` on your Samsung (allow "Install unknown apps" once).
2. Open **ShotSort** → grant **Photos** + **Notifications** → tap **Start watching**.
3. Take a screenshot → tap the "Sort screenshot?" notification → choose folder → done. Check Gallery — it's in that album.

## Privacy
100% offline. No account, no cloud, no tracking. MIT license.
